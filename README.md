# Mac-Token-Plan

macOS 桌面用量面板，集中查看 AI 服务的订阅额度、账户余额和使用趋势。支持桌面卡片与菜单栏摘要，数据在本机采集和展示。

[下载 macOS 版本](https://github.com/luolei2088-AI/mac-token-plan/releases/latest) · [查看更新记录](CHANGELOG.md)

要求：macOS 14 或更高版本。

> 当前发布包可能尚未经过 Apple Developer ID 签名和公证。首次打开时若 macOS 提示无法验证应用，请确认安装包来自本项目 GitHub Releases，再到「系统设置 → 隐私与安全性」允许打开。详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 新版功能

### Codex 账户详情

- 查看账户订阅类型、账户额度窗口、模型额度窗口和重置倒计时。
- 展示 Codex CLI 返回的可用模型及推理能力；点击模型名称复制模型 ID。
- 显示可用的用量重置卡，每张卡单独提供使用按钮，并在使用前确认。
- 查看 Codex 返回的累计 Token 数、单日峰值和每日 Token 用量图表。
- 指向 Codex 用量区域可展开详情；点击用量区域可打开 [ChatGPT](https://chatgpt.com/)。

### DeepSeek 账户详情

- 展示账户可用状态、各币种余额、充值余额和赠金余额。
- 查询当前可用模型、上下文窗口和最大输出长度；点击模型名称复制模型 ID。
- 指向 DeepSeek 用量区域可展开详情，点击可打开 [DeepSeek 用量页面](https://platform.deepseek.com/usage)。
- 统计页面按相邻成功采样的余额减少额估算花销。

### 桌面卡片与菜单栏

- 卡片集中显示各平台额度、已用比例、余额和重置倒计时。
- 可选详细或精简展示；精简模式同步减少菜单栏摘要内容并缩窄卡片。
- 可单独隐藏桌面卡片，同时保留菜单栏入口。
- 支持拖动卡片、锁定位置、调整窗口大小、选择窗口层级、浅色/深色主题、透明度和圆角。
- 菜单栏按平台轮换显示精简用量摘要，可从菜单刷新数据、切换桌面卡片显示、打开设置或退出。

### 用量统计

- 查看近 1 天、7 天和 30 天的额度消耗趋势，按小时或按日汇总。
- 可按渠道和额度维度筛选；图表悬停显示对应时段和数据。
- 分别查看 Codex Token 用量与 DeepSeek 余额花销估算。
- 本地保存历史采样，支持回看使用趋势。

## 支持的平台


| 平台           | 展示内容                            |
| ------------ | ------------------------------- |
| OpenAI Codex | 账户与模型额度、重置时间、重置卡、可用模型和 Token 用量 |
| DeepSeek     | 账户余额、可用状态、模型列表和余额变化花销估算         |

## 数据与统计说明

- API 凭证由用户在本机配置；Codex 可复用本地 Codex CLI 登录状态。
- DeepSeek 花销根据两次成功采样之间的余额减少额估算。充值、赠金变化和离线期间的完整消费无法仅靠余额还原，实际费用以平台账单为准。
- 额度统计按各平台和额度窗口分别计算；无采样数据的时段不会推算消耗。

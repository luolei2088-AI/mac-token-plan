# mac-token-plan

macOS 桌面常驻额度小组件，在桌面和菜单栏查看各模型平台的订阅用量与余额，无需反复打开控制台。

支持 macOS 14+。获取应用：[下载安装包](https://github.com/luolei2088-AI/mac-token-plan/releases/latest) · [版本更新记录](CHANGELOG.md)

> **首次打开提示**：当前安装包尚未经过 Apple Developer ID 签名和公证，可能提示“Apple 无法验证此 App”。确认安装包来自本项目 GitHub Releases 后，点击「完成」，前往「系统设置 → 隐私与安全性」，找到 `mac-token-plan` 的拦截提示，点击「仍要打开」并确认。无需关闭 macOS 安全保护。详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 支持平台

| 平台 | 查询内容 |
| --- | --- |
| MiniMax 月度订阅 | 5小时 / 7天额度 |
| 智谱 GLM Coding Plan | 小时窗口 / 7天 / 总额度，按实际返回显示 |
| 火山方舟 Agent Plan | 5小时 / 7天 / 月度总额度 |
| OpenAI Codex 订阅 | 账户与模型独立额度池，按来源分组显示额度窗口 |
| DeepSeek 开放平台 | 充值余额，以及按余额变化估算的分时段花销 |
| 百炼 Token Plan 中国站个人版 | 已用百分比与重置时间，按实际返回显示 5小时 / 7天窗口 |

## 桌面额度卡片

- 常驻桌面的透明卡片，支持拖动、调整大小、位置记忆和锁定位置。
- 按平台显示额度进度、已用百分比或余额；同一平台的多个额度池标明来源。
- 进度条随已用占比显示绿色、橙色或红色，帮助识别接近用完的额度。
- 重置倒计时实时更新，短窗口显示小时与分钟，长窗口显示天数与小时。
- 平台可单独开关，并通过拖动调整顺序，修改后即时生效。

## 菜单栏显示

- 可选在 macOS 顶部菜单栏滚动显示各平台额度，每 5 秒切换平台。
- 菜单栏与桌面卡片共享平台顺序和显示维度。
- 点击菜单栏可立即刷新、打开设置或退出应用。

## 使用量统计

- 查看近 1天、7天、30天的消耗汇总与趋势，按小时或按日展示，并标明实际起止时间。
- 只展示设置中开启的渠道，开关与排序即时生效；点击渠道汇总卡片或使用筛选项，查看单个渠道和统计维度。
- 各渠道、额度来源与额度窗口独立统计，分组柱状图避免不同额度窗口相加；额度消耗统一用 `%` 显示，累计跨重置周期可超过 100%。
- 鼠标悬停显示时间段、渠道、窗口及具体数值，明确区分零消耗与无采样数据。
- DeepSeek 独立展示金额花销汇总和趋势，不同币种分开统计，小额花销最多显示六位小数。
- 支持浅色 / 深色主题及窗口缩放；本地保留 90 天历史采样，首次采样建立基线。

DeepSeek 花销按相邻两次成功采样的余额减少额估算，余额增加不计花销。金额统计从新版完成两次成功采样后开始；充值、赠金变化及离线期间的完整消费无法仅靠余额还原，实际费用以平台账单为准。旧版本额度历史可能包含启动时的已用额度。

## 平台接入

- **API 密钥**：MiniMax、智谱、火山和 DeepSeek 在设置中配置凭证。
- **CLI 接入**：百炼、Codex 支持检测已有 CLI、安装、浏览器登录及连接检查。
- CLI 安装到应用管理的用户目录，无需管理员权限；已有 CLI 可直接复用，也可指定路径。
- 安装和登录支持取消及失败重试，设置中可查看 CLI 版本、路径和连接状态。
- Codex 兼容本应用登录、已有本地 CLI 文件凭证和高级配置中的备用 Access Token。

## 刷新与个性化

- 支持手动刷新，以及 1、5、15、30 分钟的定时刷新。
- 刷新失败时保留上次额度并标红。
- 支持按 5小时、7天、总额度控制显示维度。
- 可设置窗口层级、浅色或深色主题、透明度和圆角。
- 支持开机自启和菜单栏显示开关。
